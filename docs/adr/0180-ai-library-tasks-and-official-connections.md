# ADR-0180：馆藏 AI 任务与官方模型连接

- 状态：Accepted
- 日期：2026-11-26

## 背景

[作品繁中翻译需求](https://github.com/peach-mitao/peach/issues/393)涉及标题与简介。来源原词未映射、封面上可观察到的视觉属性，也需要逐条确认的标签建议。[ADR-0003](0003-ai-provider-boundaries.md)规定推理与智能体分离，[ADR-0153](0153-content-translations-live-beside-originals.md)规定译文与原文并存。

## 决策

- Claude、OpenAI 和 DeepSeek 的 API Key 连接默认使用官方端点，也可配置兼容该服务协议的 API 基础地址和端口。模型目录、验证和推理共用这个地址。改用其他地址时须重新输入 API Key，并主动读取新目录。远程地址需要 HTTPS，本机回环也可使用 HTTP。连接固定到已核验的 IP，保留原主机的 TLS 证书校验，并拒绝重定向。模型按任务选择，连接间没有自动切换。
- 「AI 接入」独立页面按服务商组织连接，OpenAI 同一卡片内可切换 API Key 和 ChatGPT 订阅。已保存的连接、正在填写的 API Key 及新授予的订阅权限都可读取对应模型目录，模型由用户下拉选择。读取目录和验证连接均为只读请求，保存是独立操作。目录收录的模型实际推理时仍受用量和任务能力限制。
- 用户可添加多条独立的自定义服务商连接，选择 OpenAI Chat Completions 或 Anthropic Messages 兼容协议，并配置名称、基础地址、端口及 API Key。支持读取模型目录，也可填写服务商提供的模型 ID。任务配置、助手和 Peach 用量记录使用连接的独立标识。更换地址或协议需要重新填写该连接的凭据。
- 保存后的 API Key 仅由服务端读取，Windows 用当前用户的 DPAPI 保存，其他系统使用权限为 `0600` 的本机凭据文件。连接接口只返回状态。公网域名、公开网络地址和代理转发请求均无法调用 AI 接口，即使持有有效登录。直连私网设备须先登录，本机回环沿用同源校验。非回环地址上的 API Key 提交需要 HTTPS。以相同操作系统身份运行的程序仍拥有该身份的文件和解密能力。
- 「任务与提示词」允许覆盖全局指导、搜索与任务识别、翻译、文本标签、封面与单帧、时间轴、官方样张、元数据计划和整理计划。默认指导随界面语言，自定义内容按原文使用。模型接收当前操作的指导与固定契约，作品资料作为单独输入传入。元数据与整理提示词由搜索规划使用，写入仍由应用执行确认流程。
- OpenAI 另外提供 ChatGPT 订阅连接。Peach 使用 OpenAI 的开源应用注册流程，在同一台主机接收回环回调，并将用户明确授予的订阅额度用于 Responses API。这是 Peach 自己获得的授权。现有 Codex 与 Claude 登录资料由各自运行时管理。[OpenAI 授权说明](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
- Claude 使用用户在 Claude Console 创建的 API Key。Anthropic 将个人订阅 OAuth 限定于原生应用的用途。Claude Platform OAuth 提供单独的组织计费测试版，需要登记 OAuth 应用、配置工作负载身份，并由合格 Claude 组织授权。[Claude Code 凭据政策](https://code.claude.com/docs/en/legal-and-compliance) · [Claude Platform OAuth](https://platform.claude.com/docs/en/manage-claude/oauth-apps/overview)
- 作品详情提供翻译、文本标签与视觉标签任务。题材、角色和关系从已有的作品字段和资料快照取证。视觉可自动用已有时间轴缩略图或九宫格，也可手选一张封面或预览帧。界面在提交前显示接收方和张数上限。自动模式先筛去黑场和近重复图，按时间段与画面变化选至多 18 帧，必要时用已有的邻近缩略图补证，最多发送 24 张次。姿势与镜头观察独立于馆藏标签，体位和行为候选要求同一组的相邻帧证据。
- 官方样张作为独立画面输入。使用番号已关联的发行方样张地址与现有图片缓存，最多分析 12 张，用于服装、外貌、布景等静态观察。证据引用样张编号，不从图片排序推断正片时间或行为顺序。
- 翻译目标可选繁体中文（台湾）、简体中文和英语。点击标题操作栏中的 AI 助手按钮会打开模态窗口。首次打开时读取当前目标语言的译文，缺少译文时按任务配置生成草稿。英语界面默认选择英语。
- 从全局搜索进入独立的 AI 搜索页。AI 按搜索任务配置将自然语言转成限定字段的条件，再立即搜索所选范围。用户可以展开条件、修改后重搜并保存浏览器预设。执行时复用馆藏筛选或 JavDB 的公开查询，只显示来源实际返回的作品。查询不写入账本。
- 任务配置分别保存服务、模型和思考强度。没有任务配置时优先使用已连接的官方服务和该连接的模型，其次使用自定义接入点。任务页按翻译、文本标签、画面标签及搜索从当前目录预选建议，保存后用于相应任务。自定义目录可报告视觉输入和逐模型思考档位。目录未报告档位时建议沿用模型默认，用户仍可手动选择协议支持的档位。
- 「任务与提示词」使用同一个任务选择和保存入口。时间轴和官方样张共用画面标签的模型配置，元数据和整理共用搜索的模型配置，各自保留独立提示词。全局提示词应用于全部任务。
- 自定义任务保存名称、提示词和可选的服务、模型与思考强度。AI 助手从输入框下方的「馆藏工具」选择任务。任务以用户填写的文字为输入，结果和用量显示在当前对话。
- 模型栏显示本任务的首选模型，思考强度栏显示当前所选模型在该任务下的推荐档位。选用推荐档位只调整当前模型的强度，保存后生效。默认建议依据工作负载和模型可用档位制定。[OpenAI 模型选型](https://developers.openai.com/api/docs/guides/model-selection) · [Claude 思考强度](https://platform.claude.com/docs/en/build-with-claude/effort) · [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)
- 「AI 用量」展示由 Peach 发起的请求，提供按主机日期与服务聚合的 7、30、90 天历史，以及按实际模型和任务汇总的输入与输出 token。已收到用量的失败推理也计入统计。每日计数存于本机状态目录。API 账户对比使用用户填入的同账户、同区间 token 总量及可选上限。ChatGPT 订阅额度到 [ChatGPT 用量设置](https://chatgpt.com/settings/usage) 查看。
- 文本候选必须能逐字回指已提供的文字。视觉候选限现有词表内可观察的属性，候选保留证据帧编号和取得的时间点。用户采纳后，标签沿用手动标签写入路径，模型来源与证据记在作品标签关系上。
- 首个译文投影在详情页显示，按语言独立保存标题与简介。原文变化后旧译文不再匹配，重新确认可更新相应译文。以后实现全局内容显示语言时，再接入列表、搜索和用户脚本投影。
