# ADR-0176 JavDB 本机浏览器登录与后台会话后备

- 状态：已采纳
- 日期：2026-11-25
- 关系：修订 [ADR-0166](0166-javdb-background-reads-are-anonymous.md) 的后台取页规则，沿用账号停用与出口冷却判据

## 背景

部分搜索结果、作品和演员页需要 JavDB 会话。手动导入的 Cookie 已可供用户主动打开的入口使用，后台任务只能取得公开页面。用户要求这些任务也能读取需登录的页面，并简化登录后保存会话的操作。

## 决策

1. 用户从本机 Peach 打开独立浏览器窗口，在 JavDB 官网登录。Peach 确认登录后仅保存此窗口中的 JavDB 会话到来源凭据库。手动粘贴或导入 Cookie 也写入同一位置。
2. 馆藏补资料、批量刮削、订阅拉取和定时查找先走公开入口。官网明确返回登录墙时，使用已保存的会话向原地址重试一次。此重试仅访问官方主机，重定向也受同样限制。
3. 账号请求与匿名请求使用各自的连接池。后台账号重试共用 12 秒间隔，计入原任务的网络预算，并遵守来源冷却。服务明确拒绝会话后，当前连接池继续使用匿名查询。
4. 「检查已保存的登录会话」读取官网个人资料页，连接检查独立展示网站和图片主机的可达性。

已有凭据直接供新入口使用。会话更新后，下次任务使用更新后的凭据。原有结果和候选按现有更新规则处理。
