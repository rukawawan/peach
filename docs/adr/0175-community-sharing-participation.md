# ADR-0175：共建计划使用一个参与入口

- 状态：已采纳
- 日期：2026-11-24
- 关系：修订 [ADR-0173](0173-public-metadata-contributions.md) 与 [ADR-0112](0112-complete-library-sharing.md) 的设置页交互。

设置页在「Peach 共建计划」使用一个参与开关。开启前在同一预览中显示馆藏与偏好研究、公开资料候选的分享范围、用途和本机实际内容。点击「同意并参与」同时确认两类用途，关闭开关停止两类分享。技术诊断单独设置。

两类快照继续使用各自的授权记录、投影和发送回执。服务端先验两份预览凭据，再保存缺少的授权。保存步骤部分失败时返回实际参与状态及失败项，允许用户再次操作。旧安装已授权哪一类就继续参与哪一类，页面标出部分参与状态。参加完整计划需要用户重新预览并确认。

首次设置和安装器可按已披露的字段范围参加馆藏研究。完成设置后可以预览本机公开资料候选，按实际内容确认是否参加完整计划。
